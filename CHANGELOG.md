# Changelog

Meaningful changes to the HORTOS Constitution are recorded here. Minor copy edits and link repairs do not require entries.

## 2026-07-28 — Repository Governance v1 initiated

### Added

- Repository purpose and authority hierarchy.
- Contributor onboarding through `START-HERE.md`.
- Founder-facing project dashboard in `STATUS.md`.
- Phased constitution roadmap.
- Governance and contribution standards.
- Open-decision register.

### Established

- The repository is the canonical source of truth for product, design, engineering, data, AI, and operating decisions.
- The repository must preserve project state so the founder does not need to remember what is complete or what comes next.
- Accepted ADRs and approved constitutional documents outrank specifications, roadmaps, drafts, and research.
- AI-generated work follows the same review and authority rules as human-authored work.
